Politica de Privacidad

Ultima actualizacion: 25 de octubre de 2026

Esta Politica de Privacidad describe como Flipern (en adelante, "la Aplicacion"), desarrollada por Francisco de Borja Ramiro Larrinaga, trata la informacion de sus usuarios.

1. Informacion que recopilamos

La Aplicacion puede recopilar o tratar los siguientes tipos de informacion:

  • Datos introducidos por el usuario: informacion sobre productos (nombre, precio, fotos, notas) y ventas que el propio usuario introduce en la app. Estos datos se almacenan unicamente en el dispositivo del usuario.
  • Fotografias: la app accede a la camara y a la galeria del dispositivo unicamente cuando el usuario lo solicita expresamente para anadir fotos a sus productos. Las imagenes se almacenan localmente en el dispositivo.
  • Datos de publicidad: la Aplicacion utiliza Google AdMob para mostrar anuncios. AdMob puede recopilar identificadores de dispositivo y datos de uso con fines publicitarios. Consulta la Politica de Privacidad de Google para mas informacion.
  • Datos de compras integradas: la Aplicacion utiliza RevenueCat para gestionar suscripciones y compras. RevenueCat puede procesar datos de transacciones. Consulta la Politica de Privacidad de RevenueCat.

2. Uso de la informacion

La informacion introducida por el usuario se usa exclusivamente para el funcionamiento de la app. No vendemos, compartimos ni cedemos datos personales a terceros, salvo los servicios indicados (AdMob, RevenueCat) que operan bajo sus propias politicas.

3. Almacenamiento de datos

Todos los datos del inventario y las ventas se almacenan localmente en el dispositivo del usuario mediante una base de datos SQLite. No disponemos de servidores propios que almacenen informacion personal.

4. Permisos del dispositivo

  • Camara: para fotografiar productos.
  • Almacenamiento: para guardar y recuperar imagenes de productos.
  • Internet: para mostrar anuncios y gestionar compras integradas.
  • Notificaciones: para recordatorios sobre productos sin vender.

5. Servicios de terceros

  • Google AdMob - publicidad
  • RevenueCat - compras integradas
  • Expo - plataforma de desarrollo

6. Menores de edad

La Aplicacion no esta dirigida a menores de 16 anos y no recopila conscientemente datos de menores.

7. Cambios en esta politica

Podemos actualizar esta Politica de Privacidad ocasionalmente. Los cambios se publicaran en esta misma pagina con la fecha de actualizacion revisada.
